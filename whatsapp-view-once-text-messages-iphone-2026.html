WhatsApp View Once Text Messages on iPhone: New iOS Beta Feature (2026)

By Khan Tech Review · 6–8 min read · Published November 24, 2026
Illustration: WhatsApp View Once text messaging feature on iPhone.

WhatsApp is testing a new privacy feature that lets some iPhone beta users send text messages designed to be opened only once. Called View Once Text Messages, the option extends WhatsApp's existing View Once approach beyond photos, videos and voice messages.

The feature was reported in WhatsApp beta for iOS version 26.45.10.73, distributed through Apple's TestFlight platform. According to WABetaInfo, access is being rolled out gradually to selected beta testers. It is not yet available to every iPhone user, and no public release date has been confirmed.

Availability: This is a beta feature. Even people using the compatible beta version may not see it until WhatsApp enables it for their account.

1. What Is WhatsApp View Once Text Messaging?

View Once text messaging is a reported WhatsApp feature that allows a sender to share a written message that the recipient can open in a separate viewing screen. After the recipient closes that screen, the message content becomes inaccessible in the chat.

Normal text messages remain in a conversation until someone deletes them or the chat's settings remove them. View Once is different because it is intended for a single opening. WhatsApp already offers View Once for supported media; this test brings a similar option to text.

2. How Does the New Feature Work?

When the option is available, the sender writes a message and presses and holds the Send button to open an additional menu. The reported menu includes an option to send the text using View Once.

The recipient taps the special message bubble to read it in a separate interface. When that interface is closed, the text is removed from normal access and an opened indicator appears in the conversation. The sender can see that the message was opened, subject to WhatsApp's read-receipt behavior.

3. How to Send a View Once Text Message on iPhone

If WhatsApp has enabled the feature for your beta account, the reported steps are:

  1. Open WhatsApp on your iPhone.
  2. Open an individual or group conversation.
  3. Type the text you want to send.
  4. Press and hold the Send button instead of tapping it normally.
  5. Look for the View Once option in the menu.
  6. Select View Once to send the message.
  7. The recipient can tap the message bubble to read it once.
Important: Reports say selecting View Once sends the message immediately. Check the wording and recipient carefully before selecting it. If the option is missing, your account may not have received access yet.

4. Privacy and Security Features

Reports describe several restrictions intended to make the temporary text harder to keep or share through WhatsApp:

Screenshot and screen-recording restrictions

WhatsApp reportedly blocks screenshots and screen recordings while the View Once text is open on supported iPhone beta versions.

Copying and forwarding restrictions

The recipient reportedly cannot select and copy the text or forward it using WhatsApp's normal forwarding option.

One-time viewing

After the recipient closes the separate viewing screen, the message content is no longer available to open again in the chat.

Privacy warning: These controls are not a guarantee that information can never be retained. Someone could photograph the screen with another device or remember the content. Do not use View Once as a secure way to send passwords, banking details, identity documents or other highly sensitive information.

5. View Once vs Disappearing Messages

Both options are designed to keep some content from remaining in a chat indefinitely, but they work differently.

FeatureView Once TextDisappearing Messages
How it worksDesigned to be opened onceMessages are removed after a selected time
When it disappearsAfter the viewing screen is closedWhen the selected timer expires
ScopeSelected messageChat setting applies to messages in that chat
Main purposeOne-time viewingTime-limited chat history

View Once is intended for a single opening. Disappearing Messages are better suited to conversations that should be removed after a chosen period.

6. Is WhatsApp View Once Available on iPhone?

As of November 24, 2026, WABetaInfo reports that the feature is rolling out to selected testers using WhatsApp beta for iOS version 26.45.10.73 through Apple's TestFlight programme.

This is not a general release for all iPhone users. The rollout is gradual, and having a beta version does not guarantee that the feature will appear on every account. WhatsApp has not announced a confirmed public release date.

If you already participate in the official TestFlight beta, check TestFlight for available WhatsApp updates. Do not install unofficial or modified WhatsApp apps to try to access unreleased features.

7. What About Android?

WABetaInfo previously reported the View Once text feature in WhatsApp beta for Android, including beta version 2.26.45.6. The feature is also being tested on iOS, but availability can vary by platform, app version and account.

There is no confirmed date for a full public rollout across Android and iPhone. Check reliable feature reports and official WhatsApp updates for changes.
