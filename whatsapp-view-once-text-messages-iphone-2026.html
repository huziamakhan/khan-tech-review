WhatsApp View Once Text Messages on iPhone: New iOS Beta Feature (2026)

By Khan Tech Review | 6–8 min read | Published November 24, 2026

WhatsApp is testing a new privacy feature that allows iPhone users to send text messages that can only be opened once. Called View Once Text Messages, this feature expands WhatsApp's existing temporary messaging options and gives users more control over private conversations.

The feature was spotted in WhatsApp beta for iOS version 26.45.10.73, distributed through Apple's TestFlight platform. According to WABetaInfo, it is currently rolling out to selected beta testers.

Availability: This feature is currently limited to selected iOS beta testers. It is not yet available to every iPhone user, and WhatsApp has not confirmed a general public release date.

1. What Is WhatsApp View Once Text Messaging?

WhatsApp View Once Text Messages is a feature designed to let users share written messages that recipients can read only one time.

Regular WhatsApp text messages remain visible in chat history until they are deleted. View Once messages work differently. The recipient opens the message in a separate viewing interface, and after closing it, the original text becomes inaccessible.

WhatsApp already supports View Once for photos, videos and voice messages. The new development brings a similar experience to ordinary text conversations.

2. How Does the New Feature Work?

The process is simple when the feature is enabled on an account. Users type their message and access an additional sending option by pressing and holding the Send button.

The recipient sees a special message bubble. Tapping that bubble opens the text in a separate screen. Once the viewing screen is closed, the message disappears and an opened indicator remains in the conversation.

3. How to Send a View Once Text Message on iPhone

If WhatsApp has enabled the feature for your beta account, follow these steps:

  1. Open WhatsApp on your iPhone.
  2. Open an individual or group conversation.
  3. Type the text message you want to send.
  4. Press and hold the Send button.
  5. Look for the View Once option in the menu.
  6. Select View Once to send the message.
  7. The recipient can tap the message bubble to read it.

Important: Selecting View Once sends the message immediately according to the reported beta behavior. Check your message carefully before choosing this option.

If the View Once option does not appear, the feature may not have reached your account yet. Installing a beta update does not guarantee immediate access.

4. Privacy and Security Features

The main purpose of this update is to make temporary text sharing more private. The reported feature includes several restrictions while the recipient views the message.

Screenshot Protection

WhatsApp blocks screenshots and screen recordings while the View Once text is open on supported iPhone beta versions.

Copying Restrictions

Recipients cannot use the normal text selection and copying options to save the message content.

Forwarding Restrictions

The message cannot be forwarded through WhatsApp's normal forwarding feature.

One-Time Viewing

After the recipient closes the viewing interface, the text cannot be opened again. An opened indicator replaces the message content in the chat.

Privacy warning: These protections are not a complete guarantee. Someone could still photograph the screen using another device or remember the information. Avoid sharing passwords, banking credentials or highly sensitive information through temporary messages.

5. View Once vs Disappearing Messages

Both features remove messages from WhatsApp conversations, but their behavior is different.

Feature View Once Disappearing Messages
Viewing One time Multiple times before expiry
Removal After viewing and closing After selected duration
Main purpose Temporary private content Temporary conversations
Timer required No Yes

View Once is useful when a message should be opened only once. Disappearing Messages are more suitable for conversations that should automatically be removed after a selected period.

6. Is WhatsApp View Once Available on iPhone?

As of November 24, 2026, the feature has been reported in WhatsApp beta for iOS version 26.45.10.73 through Apple's TestFlight platform.

Only selected beta testers currently have access. The feature is being rolled out gradually, so even some beta users may not see it immediately.

To check for official WhatsApp beta access:

  1. Open Apple's TestFlight app.
  2. Check whether WhatsApp beta is available to your account.
  3. Install the latest available beta version if you are enrolled.
  4. Open WhatsApp and check whether the View Once option appears.

Do not download unofficial applications or modified WhatsApp versions to access unreleased features.

7. Will Android Users Get This Feature?

View Once text messaging was also reported in WhatsApp beta for Android before the iOS testing. The Android beta version associated with the earlier rollout was 2.26.45.6.

This suggests that WhatsApp is working to bring the feature to both major mobile platforms. However, rollout schedules can differ, and there is no confirmed general release date for all Android and iPhone users.

8. Frequently Asked Questions

1. What are WhatsApp View Once Text Messages?

They are temporary text messages that a recipient can open and read only once. After closing the viewing screen, the content becomes inaccessible.

2. Can I use View Once text messages on every iPhone?

No. The feature is currently rolling out to selected WhatsApp beta testers. It is not available to every iPhone user.

3. Can someone take a screenshot of a View Once text?

WhatsApp reportedly blocks screenshots and screen recordings while the message is open on iPhone. However, another device could still photograph the screen.

4. Can View Once messages be forwarded?

The reported feature prevents recipients from forwarding the temporary text through WhatsApp's normal forwarding option.

5. Which iOS beta version includes this feature?

The feature was spotted in WhatsApp beta for iOS version 26.45.10.73 through Apple's TestFlight platform.

6. Is View Once the same as disappearing messages?

No. View Once messages disappear after being opened and closed, while disappearing messages are removed after a selected time period.

7. When will the feature be available to everyone?

WhatsApp has not announced a confirmed public release date. The feature is currently in a gradual beta rollout.

Final Thoughts

WhatsApp's View Once text messaging feature is an interesting addition to its privacy tools. It gives users another way to share temporary information without leaving the text visible in ordinary chat history.

However, the feature is still being tested with selected beta users. Its privacy protections can reduce casual copying and sharing, but they cannot guarantee that a recipient will never retain the information.

For now, iPhone users should keep their WhatsApp application updated through official channels and wait for wider availability.
